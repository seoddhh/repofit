# 게시한 오픈소스 해설 기록

`2026-10-18.json`은 2026년 10월 18일 작성하고 게시한 해설 10개의 본문과 공식 출처를 보관합니다. 각 글의 작성 시각과 자료 수집 시각은 ISO 8601 UTC로 기록합니다. 전체 README 원문, 사용자 정보, 인증 정보, DB 파일은 포함하지 않습니다.

사이트는 이 파일을 직접 읽지 않고 D1의 `repository_briefs`를 조회합니다. 따라서 이 기록을 Git에 올리는 것만으로 사이트 본문이 갱신되지는 않습니다. 로컬 D1과 배포 D1도 별도 저장소입니다. 이번 작성본은 양쪽 DB에 반영하고 조회 결과를 확인했습니다.

본문 변경은 코드·UI 변경과 별도 커밋으로 관리합니다. 새 글을 게시할 때는 [조사·해설 스킬](../../skills/repofit-editorial/SKILL.md)과 [사이트 연동 계약](../../skills/repofit-editorial/references/site-integration.md)을 따릅니다. 이 기록은 게시 결과의 버전 보관용이며, 사이트 게시·배포·Git 푸시 권한을 부여하지 않습니다.
